# Freedom Solutions Transport

A historical transportation landing-page project built with HTML, CSS and Bootstrap 4.
Open `index.html` or serve this directory using `python -m http.server 8000`.

The copy, pricing, testimonials and telephone contact are historical project content,
not a verified current booking service. Booking links lead to the page contact section;
there is no reservation backend. External fonts, Bootstrap and Font Awesome require
network access. Local asset paths work on case-sensitive web hosts.
